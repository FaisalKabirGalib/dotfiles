# Web Design Profile

Use this profile only for web UI work. Start from the project's existing design system; if none exists, select one intentional direction from Awesome Design MD or UI UX Pro Max rather than mixing visual styles. Record chosen tokens, typography, spacing, and component rules in project-owned design documentation.

Build accessible, responsive interfaces with semantic HTML, keyboard support, visible focus states, reduced-motion support, clear empty/loading/error states, and sufficient contrast. Use Vercel web-design guidance for implementation review.

Use UI UX Pro Max project-locally for design-system generation or stack-specific UI guidance. Verify meaningful UI changes with `agent-browser` at desktop and mobile widths. Do not make UI UX Pro Max or large design-reference collections global defaults.
