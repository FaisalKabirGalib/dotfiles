# Flutter Profile

Use Dart sound null safety and follow the app's existing state-management and routing patterns. Prefer feature-oriented structure, keep business logic out of widgets, and run `dart format` plus the narrowest available Flutter or Dart analysis command after relevant changes.

Use the official Dart and Flutter skills plus `dart mcp-server` when Dart 3.9+ is available. Use MCP tools only against the current project and a running local app; do not connect to unrelated devices, accounts, or production services.
