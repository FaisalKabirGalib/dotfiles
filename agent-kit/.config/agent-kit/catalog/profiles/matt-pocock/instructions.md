# Matt Pocock Profile

Use Matt Pocock's skills as small, composable engineering workflows. Begin uncertain or substantial code changes with `grill-with-docs`; use `tdd` for features and bug fixes; use `code-review` and `handoff` at natural delivery boundaries.

Use `wayfinder`, `to-spec`, and `to-tickets` for initiatives with unresolved decisions before implementation. Use `improve-codebase-architecture` and `codebase-design` for deliberate architecture work, not routine edits. Configure a project issue tracker and documentation location through `setup-matt-pocock-skills` before workflows that create tickets or domain documentation.

Do not combine this profile's planning workflow with GSD for a small task. For larger work, use Matt Pocock's clarification and decision skills first, then choose either GSD's phased execution or the repository's normal delivery flow.
