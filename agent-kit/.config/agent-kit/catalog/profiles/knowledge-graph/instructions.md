# Knowledge Graph Profile

For code-only repositories, prefer the existing `understand` workflow and its project-owned `.ua` knowledge graph. Use Graphify only when a task needs a single queryable graph across code plus external documents, PDFs, images, or video.

Run Graphify project-locally and review its model-provider, extraction, and storage settings before processing private material. Do not enable global hooks or send secrets, credentials, customer data, or unrelated home-directory files to a graph extraction workflow.
