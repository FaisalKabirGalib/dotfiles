# Workflow Profile

Use Get Shit Done (GSD) only as a project-local workflow for substantial, multi-phase work that benefits from explicit discovery, planning, execution, and verification. Do not install it globally and do not use any unsafe permission-bypass mode.

Keep Agent Kit as the canonical policy source. Use GSD for task state and phased execution; do not let it overwrite project-owned instructions, hooks, or harness configuration without review.
