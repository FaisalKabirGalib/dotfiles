# zsh — Zsh Shell Configuration

Zsh shell with Zinit plugin manager and modern CLI tools.

## Package Details

- **Type**: Shell
- **Target**: `~/.config/zsh` + symlinked `.zshrc`
- **Dependencies**: Zsh, Zinit, FZF, Zoxide, bat, exa, fd, rg

## Install

```bash
stowup zsh
```

## Key Features

- Zinit for plugin management
- Powerlevel10k theme
- FZF integration (`Ctrl+R`, `Ctrl+T`)
- Zoxide for directory jumping
- Custom aliases for common tasks
