# p10k — Powerlevel10k Prompt

Zsh prompt theme for enhanced shell experience.

## Package Details

- **Type**: Shell Prompt
- **Target**: `~/.p10k.zsh`
- **Dependencies**: Zsh, Powerlevel10k

## Install

```bash
stowup p10k
```

## Key Features

- Instant prompt rendering
- Conditional icons
- Git status integration
- Ruby version display
