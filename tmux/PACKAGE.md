# tmux — Terminal Multiplexer

Terminal multiplexer with custom keybindings and session management.

## Package Details

- **Type**: Terminal Multiplexer
- **Target**: `~/.config/tmux`
- **Dependencies**: tmux >= 3.0, tpm (tmux plugin manager)

## Install

```bash
stowup tmux
```

## Key Features

- Prefix: `C-a` (instead of default `C-b`)
- Session management script: `tmux-se`
- Clipboard integration
- Vim-style navigation
- TPM plugins for status and restore
