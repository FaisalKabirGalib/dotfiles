# waybar — Wayland Status Bar

Status bar for Wayland compositors (Hyprland).

## Package Details

- **Type**: Status Bar
- **Target**: `~/.config/waybar`
- **Dependencies**: Hyprland, waybar

## Install

```bash
stowup waybar
```

## Key Features

- Workspace indicator
- Clock/date
- System info (CPU, RAM, battery)
- Media player controls
