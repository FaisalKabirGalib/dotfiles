# wezterm — Terminal Emulator

GPU-accelerated, cross-platform terminal emulator and multiplexer by wez.

## Package Details

- **Type**: Terminal Emulator
- **Target**: `~/.config/wezterm`
- **Dependencies**: WezTerm, CaskaydiaMono Nerd Font

## Install

```bash
stowup wezterm
```

## Key Features

- GPU-accelerated rendering
- Built-in multiplexing (panes/tabs/workspaces)
- Lua-based configuration
- Catppuccin Mocha theme, tmux-friendly keybindings
