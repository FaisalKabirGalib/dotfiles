# Herdr Coordination

When `HERDR_ENV=1`, use Herdr for a long-running server, watcher, test process, or independent coding agent when a sibling pane materially helps the task. Before controlling it, follow the installed `herdr` skill or run `herdr --skill`.

Use the current workspace and working directory, parse IDs from command responses, and use `--no-focus` for background work. Do not control Herdr outside a Herdr pane, change focus, close user-owned panes, or stop the server unless the user explicitly asks.
