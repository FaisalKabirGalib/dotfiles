# agy — Antigravity CLI Configuration

Custom settings, plugins, and custom agents for the Antigravity CLI.

## Package Details

- **Type**: AI Agent Configuration
- **Target**: `~/.gemini/antigravity-cli/`
- **Dependencies**: Antigravity CLI (`agy`)

## Features

- **Custom Subagents**: `arch-expert`, `code-reviewer`, `flutter-expert`, `ts-expert` in `plugins/custom-agents/agents/`.
- **Settings**: Keyboard-first configurations and trusted workspaces.
- **Stow Integration**: Seamless config management.

## Install

```bash
./stowup agy
```
